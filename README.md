# Game2Gen
### Introducing the world’s first AI game console built entirely for the web.

Game2Gen is a high-speed retro arcade and runtime environment that turns your browser into a living gaming sandbox. Powered by dynamic code execution, Game2Gen lets you discover, run, and instantly deploy playable HTML5 games with zero installation, zero lag, and zero backend overhead.

Whether you're exploring the top community creations or dropping in your own AI-generated HTML5 scripts, Game2Gen turns raw code into playable reality in milliseconds.

---

## Features

* **Instant Arcade Engine:** Fire up retro-style games directly in the browser with zero build steps or software dependencies.
* **Prompt & Deploy:** Upload single-file games or feed raw AI code straight into the sandbox for real-time play testing.
* **Isolated Execution:** Run code safely using sandboxed iframe rendering for high performance and total security.
* **Zero-Latency Discovery:** Scroll through popular arcade picks with an ultra-fluid, retro-inspired UI.
* **Pure Static Architecture:** Deploy anywhere instantly—optimized for ultra-fast hosting on Netlify, GitHub Pages, or Vercel.

---

## Tech Stack

* **Frontend:** Standard HTML5, CSS3, Vanilla ES6+ JS
* **Runtime:** Dynamic iframe injection via srcdoc
* **Deployment:** 100% Static Web Ready
